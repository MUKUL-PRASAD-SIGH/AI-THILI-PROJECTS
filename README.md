# AI-THILI-PROJECTS

A collection of projects built for the askThili programme.
Each project lives in its own folder and is developed on its own branch.

| Project | Branch | Folder |
|---|---|---|
| Support Response Generator (n-gram next-word suggester) | `support-response-generator` | `support-response-generator/` |
| AI Product Describer (GPT trained from scratch on product texts) | `ai-product-describer` | `ai-product-describer/` |
| Public FAQ Answer Bot Trainer (GPT-2 + hand-written LoRA, Streamlit) | `public-faq-answer-bot-trainer` | `public-faq-answer-bot-trainer/` |
| Game Action Predictor Dashboard (play sequences, pattern mining, causal LM; in progress) | `game-action-predictor-dashboard` | `game-action-predictor-dashboard/` |
| Event Planning Request Sorter (GPT-2 fine-tuned to classify client requests) | `event-planning-request-sorter` | `event-planning-request-sorter/` |
| Quantized Game Dialogue Simulator (GPT from scratch, int8/k-bit quantization, device simulation) | `quantized-game-dialogue-simulator` | `quantized-game-dialogue-simulator/` |
